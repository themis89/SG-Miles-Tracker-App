## Kana Dojo

`kana-trainer.html` is a standalone hiragana/katakana flashcard trainer — open it directly in a browser, no build step. Features a 5-minute spaced-repetition practice session, a mastery-tracked progress grid, and randomly-timed "surprise tests" (every few days) that quiz everything learned so far and log the score trend. Progress is saved locally (localStorage) with export/import for backup.
